# Clientes

A Central guarda o cliente (pessoa física ou jurídica), o documento e os contatos. Não guarda senha de usuário do aplicativo nem nome de pessoa da paróquia.

O cadastro, o documento e o que a Central não armazena estão na [arquitetura, seção 4.1](../arquitetura-central.md) e nas regras do [AGENTS.md](../../AGENTS.md).
