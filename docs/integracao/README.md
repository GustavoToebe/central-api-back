# Integração com os aplicativos

O aplicativo autentica com HMAC. A Central envia a instância e os direitos, recebe erros 5xx e consulta os códigos de recurso que o aplicativo entende.

O texto assinado, os caminhos e os códigos de erro estão no [contrato v1](../contrato-integracao-v1.md). O fluxo de provisionamento está na [arquitetura, seções 5 a 7](../arquitetura-central.md).
